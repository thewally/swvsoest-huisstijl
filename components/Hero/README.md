# Hero

De openingsband van de homepage: het gesplitste groen/blauwe veld uit het schild, met het handdruk-beeldmerk op de groene helft en de tekst op de blauwe helft.

- Gebruik hem alleen op de homepage en op grote landingspagina's, één keer per pagina.
- `title`: kort, hooguit acht woorden, in de display-letter.
- `intro`: één of twee zinnen. `label`: optioneel, bijvoorbeeld "VVZ’49 × So Soest".
- `actions`: één primary-knop (die hier navy wordt) en eventueel één quiet-knop.
- `markSrc`: `assets/Logos/beeldmerk-handdruk.svg`. Op mobiel verdwijnt het beeldmerk en wordt de band blauw met een groene bovenrand.
- Zet nooit tekst op de groene helft: wit op vvz-groen is te licht voor normale tekst.
