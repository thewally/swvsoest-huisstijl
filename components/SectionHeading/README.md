# SectionHeading

Kop boven een sectie: een groen kapitaal-label met een h2 eronder, en eventueel een actie rechts.

- `label`: één woord dat de sectie plaatst ("Programma", "Nieuws"); optioneel.
- `title`: de eigenlijke kop.
- `action`: meestal een quiet `Button` met `href` naar het volledige overzicht.
- `as`: het kopniveau (standaard `h2`). Pas het aan zodat de koppen op de pagina logisch blijven.
