# Button

Knop of knoplink voor de belangrijkste acties op de site.

- `variant="primary"` (groen-actie): de hoofdactie van de pagina, zoals "Word lid" of "Aanmelden". Hooguit één per scherm.
- `variant="secondary"` (blauw-actie): een tweede belangrijke actie naast primary.
- `variant="quiet"`: alles daarna, zoals "Meer nieuws".
- Geef `href` mee voor navigatie; de knop wordt dan een `<a>`. Zonder `href` is het een `<button type="button">`.
- `size="sm"` (44px hoog) alleen in de header en in compacte rijen; standaard is 48px.
- Tekst: werkwoord eerst, korte zin, hoofdletter alleen aan het begin ("Bekijk het programma").
