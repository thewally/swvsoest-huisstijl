# Lettertypes

- `ArchivoBlack-Regular.woff2`: Archivo Black, voor koppen (`--font-display`).
- `Archivo-Variable.woff2`: Archivo, variabel gewicht 100–900, voor alle overige tekst (`--font-sans`).

Beide vallen onder de SIL Open Font License 1.1 (bron: [Google Fonts](https://github.com/google/fonts)). `tokens/tokens.css` laadt ze via `@font-face` vanuit deze map.
